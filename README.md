# CEGA-Tiny: simulation code and results

Research data and code for **"CEGA-Tiny: A Confidence-Gated, Energy-Governed Controller for On-Device Learning under Concept Drift (A Trace-Driven Simulation Study)"**, submitted to the *Journal of Systems Architecture*.

## Reproduce

1. Open a notebook from `code/` in Google Colab and run all cells. The notebooks download the public datasets (UCI Gas Sensor Array Drift, UCI-HAR, Elec2 from OpenML id 151, Forest CoverType via scikit-learn, NOAA Weather; SEA is synthetic).
2. Part B takes about 9 minutes on a CPU runtime.
3. Seeds: 0-4 for the four-stream main experiments, 0-9 for the six-stream comparison, 0-2 for the sensitivity studies.
4. Local use: `pip install -r requirements.txt` (Python 3.13 was used on Colab; versions are not pinned).
